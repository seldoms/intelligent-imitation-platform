## 能力

用随机国家（英/美/德/意/法/日）、随机性别、随机年龄的虚构人格，写一篇"外国人看中国"风格的短文。表面是中国见闻，实则是褒中贬美/褒中贬西。

## 调用方式

```
/褒中贬美 <主题或素材>
```

## 输入示例

```
/褒中贬美 中国高铁
/褒中贬美 中国的移动支付
/褒中贬美 中国的夜市文化
```

## 生成模板

### 第一步：确定人格

从以下列表中随机组合：

**国家**：英国、德国、法国、意大利、日本（不选美国——因为视角是"外国人看中国"，美国作为被对比方）

**性别**：男 / 女

**年龄**：28岁、35岁、42岁、55岁、68岁

**职业**：教师、记者、工程师、退休教授、自由撰稿人、旅行博主

例如：
> 我是一个 42 岁的法国男性建筑师，第一次来中国出差。

### 第二步：文章结构

标题：一个看似平淡的陈述句（如"我在上海看到了未来"）

```
第一段：来到中国前的印象
  - "来之前，朋友说中国很落后……"
  - （先立一个西方媒体塑造的刻板印象靶子）

第二段：初到中国的冲击
  - 描写一个具体场景（高铁站/扫码支付/深夜外卖/快递机器人）
  - 细节堆叠，不空发议论
  - 和自己的国家做对比，点到即止

第三段：深入观察的感悟
  - 从表面现象延伸到社会文化层面
  - 中国人的某种品质（勤劳、友善、守秩序、重视家庭）
  - 对比自己国家的某种缺失（冷漠、效率低、基础设施老化）

第四段：升华
  - "我想起在巴黎/伦敦/东京的时候……"
  - 承认自己之前被偏见蒙蔽
  - 点到即止的结论，不长篇大论
```

### 第三步：行文规则

**必须遵守**：
- 全文 600-1200 字
- 用第一人称，保持虚构人格的口吻
- 有一个具体的"顿悟时刻"——一个细节让"我"观点改变
- 对比要含蓄（"我们那儿……"而不是"美国太差了"）
- 结尾留白，不要喊口号

**禁止**：
- 直接说"中国真棒"
- 长篇政治议论
- 二极管式的"中国好，西方坏"
- 引用官方宣传口径

以下是从数据库中提取的 284 篇"暗渡陈仓"风格范文的通用套路：

### 常见的靶子（开头用来否定）
| 靶子 | 典型表述 |
|---|---|
| "来之前以为中国很落后" | "朋友说中国连WiFi都没有" |

| "以为中国很脏乱" | "想象中是满街自行车和灰蒙蒙的天" |

### 常用的"顿悟时刻"
| 场景 | 对比点 |
|---|---|
| 高铁站 | "我们的火车站像博物馆，中国的像机场" |
| 深夜出门 | "我生活的城市晚上8点后就是空城" |
| 扫码支付 | "我还在用硬币，中国人已经刷脸了" |
| 外卖快递 | "周末想吃饭要开车出去，这里30分钟送到家" |
| 陌生人帮忙 | "在纽约/伦敦，没人会这样帮一个陌生人" |

### 结尾常见套路
| 类型 | 示例 |
|---|---|
| 对过去的反思 | "我为自己之前的偏见感到羞愧" |
| 对未来的感慨 | "不知道我们什么时候才能赶上" |
| 对人性的感悟 | "科技会过时，但人与人的温度不会" |

## 写作步骤

1. **确定人格** — 随机国家 + 性别 + 年龄 + 职业
2. **选择场景** — 从主题出发匹配一个具体场景
3. **设置对比** — 选择一个合理的对比角度
4. **按结构写作** — 先立靶子 → 场景冲击 → 深入感悟 → 含蓄升华
5. **自查** — 排除说教、排除政治议论、控制字数
