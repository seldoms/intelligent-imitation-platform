## 能力

给一个素材（新闻、故事、数据、个人经历），自动扩展成一篇有观点、有细节的杂志风格短文。

## 核心原则

**素材不是你文章的皇帝，而是你文章的起点。**

一篇好的素材改写 = 素材的精华（≤40%）+ 你的延伸（背景/故事/感悟）（≥60%）

## 参考范文

### 从科学新闻展开

**ID: 1261 — 你中午吃的那只蛤蜊也许已经好几百岁了**
- 原始素材：英国科学家发现一只 507 岁的北极圆蛤
- 展开方式：从"蛤蜊的年龄"延伸到"人类对生命的认知"→ "时间的意义"
- 可学要点：科学新闻最怕写得像论文，用生活场景开头就活了

### 从文化现象展开

**ID: 1257 — 北京烤鸭鄙视链**
- 原始素材：北京烤鸭店之间的鄙视链
- 展开方式：从"吃什么"延伸到"怎么吃"→ "为什么吃"→ 上升到文化认同
- 可学要点：一个美食现象可以写出社会学深度

### 从文学作品展开

**ID: 226 — 鲁滨孙是孤独的人吗**
- 原始素材：《鲁滨孙漂流记》这部小说
- 展开方式：质疑经典解读（他不孤独，他享受孤独）→ 重新定义"孤独"
- 可学要点：用新角度解读老素材，就是最好的文章

### 从个人经历展开

**ID: 225 — 那些年我们爱过的巧克力**
- 原始素材：小时候吃国产巧克力的记忆
- 展开方式：个人记忆 → 国产品牌的兴衰 → 消费升级的思考
- 可学要点：个人经历 + 时代背景 = 共鸣

## 结构模板

### 三段式

#### 第一段：素材核心（150-200字）

抛素材的**亮点**，不是复述整个素材。

```
❌ "据报道，某科学家发现了一只蛤蜊……经过研究发现……"
✅ "2006年，一群英国科学家在冰岛捞起一网蛤蜊，其中一只已经活了507年。
   它不是化石，不是标本，是被你吃到肚子里的那种普通蛤蜊。"
```

**技巧**：
- 找素材最让人"哇"的那一点开头
- 用场景代替数据（"你中午吃的那只蛤蜊……"）
- 一句话就够，别铺垫

#### 第二段：展开延伸（300-500字）

从素材出发走三步：

| 步 | 内容 | 篇幅 |
|---|---|---|
| 1 | 补充背景：让读者理解这个素材为什么有意思 | 100-150字 |
| 2 | 关联故事：另一个相关的事例/经历/见闻 | 150-200字 |
| 3 | 个人感悟：这件事让我想到什么 | 100-150字 |

**三种展开方向（选一个）**：

| 方向 | 适合的素材 | 示例 |
|---|---|---|
| **情感方向** | 人物故事、生活见闻 | 素材 → 类似经历 → 共鸣 |
| **知识方向** | 科学发现、历史事件 | 素材 → 深度解读 → 知识增量 |
| **观点方向** | 社会现象、争议话题 | 素材 → 多角度分析 → 观点输出 |

#### 第三段：收束（100-150字）

回到素材原点，但读者已经和开头不一样了。

```
开头：一只 507 岁的蛤蜊
结尾：所以下次吃蛤蜊的时候，你吃的可能不是海鲜，是时间
```

## 技法要点

### 1. 素材要"榨汁"

不是照搬素材，而是提取最精彩的那一滴：
- 去掉背景铺垫（"据xx报道/研究显示……"）
- 去掉过程细节（除非必要）
- 只留"结果"和"冲击"

### 2. 搭框架三选一

同一个素材往三个方向写：

```
素材：某地规定公务员学手语
→ 情感方向：一个聋哑人父亲去办事的经历
→ 知识方向：中国手语的起源和现状
→ 观点方向：规定是善意，但真正的障碍是什么
```

### 3. 加"料"三件套

- **背景知识**：让读者觉得"哦原来是这样"
- **相关故事**：让读者觉得"对对对我也遇到过"
- **个人体验**：让读者觉得"作者是真的有经历"

### 4. 素材占比控制

```
素材 40%    ← 够了
延伸 40%    ← 背景+相关故事
感悟 20%    ← 点到即止
```

## 输出约束

- 字数：600-1000 字
- 署名：标题 + 作者名 + 正文
- 禁止：照搬新闻稿、列数据表、官方口吻
- 必须：有一个让人"哇"的开头 + 一个让人"嗯"的结尾

## 示例

### 示例 1：素材"一个老人每天去地铁站坐一圈"

**处理流程**：
1. 确定方向：情感方向（个人故事）
2. 搜索参考：`/search?q=老人的日常&top_k=3`
3. 按模板展开：
   - 开头：每天早高峰，总有一个老人刷卡进站，不坐车，坐一圈就出去
   - 展开：地铁工作人员的好奇 → 追问得知老伴生前每天坐这趟线 → 后来老人不来了
   - 收束：地铁还在跑，只是少了一个刷卡的人

### 示例 2：素材"某地规定公务员学手语"

**处理流程**：
1. 确定方向：观点方向
2. 搜索参考：`/search?q=政策背后的温度&top_k=3`
3. 按模板展开：
   - 开头：规定是好的，但一个问题——谁来教？
   - 展开：手语老师的困境、聋哑人的真实需求、政策初衷vs执行
   - 收束：善意不是学了手语就能沟通，而是愿意蹲下来
