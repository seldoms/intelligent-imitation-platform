## 能力

给一句名言/金句/诗句，扩展成一篇有故事、有观点、有深度的杂志风格短文。

## 核心原则

**名言是引子，不是你文章的全部。**

好的名言扩写 = 名言（10%）+ 诠释（20%）+ 故事（50%）+ 深化（20%）

## 结构模板

### 四段式

#### 第一段：亮出名言（100-150字）

用最干净的方式引出那句名言。

```
❌ "孔子曾经说过，'学而时习之，不亦说乎'，这句话的意思是……"
✅ "朋友问我：'你每天写这些东西，图什么？'
   我脱口而出：'不亦说乎。'
   然后我才意识到，原来两千年前就有人替我回答了。"
```

**技巧**：
- 把名言放在一个具体场景里引出
- 不要"xx曾经说过"——太老了
- 最好让名言从对话/场景里自然出来

#### 第二段：诠释（150-200字）

用大白话解释这句名言是什么意思，**但不要翻译**。

```
❌ "'人生如逆旅，我亦是行人'的意思是，人生就像一家旅店……"
✅ "第一次读到这句，我正坐在深夜的火车上。
   窗外黑漆漆的，不知道到哪了。
   那一刻我突然懂了——原来我们都只是在路上。"
```

#### 第三段：用故事诠释（300-400字）

用 2-3 个故事/场景让这句名言"活"起来。

| 故事类型 | 作用 | 篇幅 |
|---|---|---|
| 正面故事 | 这句名言如何被验证 | 150字 |
| 反面故事 | 似乎违背这句名言的事 | 150字 |
| 个人故事 | 我自己和这句名言的交集 | 100字 |

**关键**：第三个故事一定要是"反着用"——先讲一个看起来和名言矛盾的事，再绕回来。

#### 第四段：深化收束（100-150字）

回到名言，但多了一层理解。读者读完的感觉：哦，原来这句话还可以这么理解。

## 技法要点

### 1. 名言只是引子

名言占全文不要超过 10%。它是一把钥匙，不是整栋房子。

### 2. 例子要"反着用"

```
名言："世界上只有一种真正的英雄主义……"
正面例子：一个面对绝症依然乐观的人（太俗）
反面例子：一个逃避现实的人 → 后来发现逃避也是一种自救 → 绕回"认清生活真相"
```

效果好得多。

### 3. 不要"这句名言告诉我们……"

这是中学作文写法。用故事代替说教。

```
❌ "这句名言告诉我们，要坚持不懈"
✅ "她每天凌晨四点起床，写了十年——不是因为坚持，是因为不写就难受"
```

### 4. 古今中外穿插

一个古代的引用 + 一个当代的故事 + 一个自己的经历 = 层次感

### 5. 结尾要比开头多一层

如果开头对名言的理解是"水平1"，结尾至少要"水平2"——不是推翻，是加深。

## 输出约束

- 字数：600-1000 字
- 署名：标题 + 作者名 + 正文
- 禁止：说教式开头、"这句名言告诉我们"、大段引用
- 必须：名言在场景中引出 + 至少一个反面例子 + 结尾有深化

## 示例

### 示例 1：名言"人生如逆旅，我亦是行人"

**处理流程**：
1. 确定角度：从"漂泊感"入手
2. 搜索参考：`/search?q=旅行的意义&top_k=3`
3. 按模板展开：
   - 开头：深夜火车上读到这句，窗外漆黑，不知道到哪了
   - 诠释：原来人生就是一直在路上
   - 故事：一个朋友买了房却说"没有归属感" / 一个流浪歌手快乐地活着
   - 深化：有房子不一定有家，在路上不一定是漂泊

### 示例 2：名言"世界上只有一种真正的英雄主义，就是认清了生活的真相后还依然热爱它"（罗曼·罗兰）

**处理流程**：
1. 确定角度：从"什么算生活的真相"入手
2. 搜索参考：`/search?q=生活的真相&top_k=3`
3. 按模板展开：
   - 开头：一个朋友在经历了最糟糕的一年后说"其实也没那么糟"
   - 诠释：她没有否定糟糕，只是选择看另一边
   - 故事：一个患病的老人每天浇花 / 一个破产的中年人重新摆摊
   - 深化：英雄主义不是轰轰烈烈，是早上还能起床吃一碗面
