## 能力

以"讲述一个值得讲的故事"为核心理念，选取一段完整的生活经历或人物往事，以清晰的叙事线索展开，在人物刻画和场景描写的交织中推进情节，同时在叙述的关键节点穿插克制的议论与感悟。叙事散文不同于抒情散文——它不依赖物象寄托情感，而是靠"发生了什么事"、"人物做了什么"来承载意蕴。叙事线索是骨架，人物细节是血肉，适度的议论是灵魂。

## 调用方式

```
/叙事散文 <主题或素材>
```

## 输入示例

```
/叙事散文 父亲教我骑自行车
/叙事散文 和奶奶的最后一次赶集
/叙事散文 十年前的那个雨夜同事
```

| 24725 | 这种母爱 | 蒋方舟 | 从同班同学的"被喂食"经历切入叙事，先叙事后议论，人物轮廓仅用寥寥数笔便跃然纸上，叙事视角由外向内的转换自然流畅 |

### 范文核心技法提取

**19728（龙眼与伞）**：双线叙事的典范。第一条线是母亲雪天送伞被"我"粗暴拒绝，第二条线是青岛友人攥着龙眼去看望儿子的悲剧。两条线索由"母爱"主题串起，但在叙事上各自独立完整。时间线从当下（写作时）回到事发当天，再到青岛会友，清晰而不凌乱。人物的一个动作——母亲弓着背夹伞离去，友人攥着龙眼上火车——就完成了全部人物塑造。

**24725（这种母爱）**：从旁观者视角切入叙事（观察同学被母亲当众喂食），先铺陈群体反应（同学的起哄），再聚焦个体（那位同学的瑟缩），最后转向普遍思考（母爱的距离问题）。叙事推进中人物形象逐层浮现：母亲的无畏、儿子的渺小、起哄者的残忍。最后的议论完全建立在前面叙事的基础上，无一句凭空而来。

**19448（父亲为什么沉默）**：叙事的主线不是某一件具体的事，而是一个持续的过程（孩子从出生到长大的全过程）。用哪吒剔骨还父的典故作为叙事的"隐喻锚点"，让读者在古典故事和现实父爱之间来回映射。"沉默"既是父亲的外在动作，也是全文的内在结构——每一段的结尾都回到"沉默"二字，形成复沓效果。

**225（那些年我们爱过的巧克力）**：以"巧克力"为叙事线索，串联起九十年代、成长期、成年后三个阶段。每个阶段都有具象的生活片段（小时候够不着柜台、长大后逛超市越来越低频、如今在黑巧中寻找优越感），叙事的推进就是时间线的推移。议论穿插在每个阶段的末尾，形成"叙一段、议几句"的节奏。

## 结构模板

### 开头（150-200字）：设定叙事起点

**写法指导**：叙事散文的开头要为读者建立一个"锚点"——一个明确的时间、地点、人物关系组合。让读者在一开始就知道"谁、在什么时候、在哪里、发生了什么事的开端"。

```
可选开场方式：
- 倒叙式：从现在的某个触动写起，然后"那是在……"回到过去（参考 19728）
- 场景式：直接进入一个具体场景，"那年冬天，我站在……"（参考 24725）
- 人物式：先交代人物关系，"我到现在还不确定，父亲是不是真的不爱说话。"（参考 19448）
```

示例开头句式（参考 19728）：
> "四月中旬的一个下午，我正在书房写作，电话响了，是母亲打来的。她说自己就在楼下，下雪了，来给我送伞。"

### 展开（400-600字）：叙事推进 + 人物刻画 + 场景描写

这是文章的主体。叙事散文的核心是"推进"，每一段都要让故事向前走一步。

**第一层（叙事开端）**：交代事件的起因或背景。写清楚是什么触发了这段叙事。"我"在什么状态下，遇到了什么事情。

**第二层（叙事发展 + 场景描写）**：进入核心事件。这里需要做到三点：
1. **时间清晰**：让读者清楚地知道事件发生的时间顺序
2. **画面支撑**：至少有一个"让读者能看见"的场景画面
3. **人物动作**：让人物"做"事情，而不是"说"想法

**第三层（叙事转折 + 人物对话/心理）**：叙事需要一个转折点——可能是"我"态度的变化、一个意外事件、一个被忽略的细节浮出水面。这一层往往需要引入人物对话或"我"的内心活动。

**第四层（叙事收束 + 适度议论）**：在叙事接近完成时，可以插入一段克制的议论。议论必须直接从叙事中生长出来，不能是外贴上去的道理。

**关键**：叙事散文的每个段落都应该回答"然后呢？"——如果一段落不推动叙事向前，就需要删掉。

### 结尾（100-200字）：余韵或回首

**写法指导**：叙事散文的结尾通常有两种方向：

- **回到当下式**：从回忆的叙事中回到"现在"，与开头形成呼应，展示时间的跨度带来的改变。不说"我学到了什么"，而是写"现在每次路过那个地方，我都会放慢脚步"。
- **留白沉思式**：叙事结束后留一段安静的空间，让读者自己去品味事件意味。可以写一个与主体叙事看似无关但意蕴相通的画面。

禁止使用的结尾方式：
- "通过这件事我明白了……"式的结论总结
- "所以我们要珍惜……"式的说教升华
- 硬塞一个与叙事无关的大道理

## 技法要点

### 1. 时间线处理

叙事散文最大的难点是时间线的组织。需要掌握三种时间线处理方式：

**顺叙**（参考 225）：按时间先后自然推进。从童年到青年到成年，读者跟随叙事者一起经历变化。优点是自然流畅，缺点是容易平铺直叙。使用时需要在每个时间节点上选择"最有画面感的一个瞬间"来写，而不是每个阶段都平均用力。

**倒叙**（参考 19728）：从"当下"的一个触发点（写作中的电话、一件旧物、一个相似的场景）闪回过去。开头的"此时此刻"和结尾的"回到当下"形成框架，中间的叙事主体全部在回忆中完成。优点是天然有结构感，容易控制节奏。

**平行叙事**（参考 19728 的双线、19448 的神话与现实并置）：两条时间线或两条故事线交替推进。一条线是"当下发生的事"，另一条线是"回忆中的事"，两条线在关键处交汇。难度最高，但效果最好——两条线的对照本身就产生意味。

**核心原则**：无论使用哪种方式，读者必须始终清楚地知道"现在是哪个时间点"。每次时间变换必须有明确的过渡句（"那是在……","很多年以后……"）。

### 2. 场景描写

场景是叙事散文让读者"进入"故事的通道。好的场景描写要做到：

**用动词代替形容词**：
| 避免 | 推荐 |
|---|---|
| "天气很冷" | "呼出的气在面前结成白雾，他跺了跺脚" |
| "火车站很乱" | "扛着蛇皮袋的人在人群中撞来撞去，广播里的声音被淹没在嘈杂里" |
| "她很疲惫" | "她靠在椅背上，眼睛闭着，手指还攥着那个袋子" |

**五感写作**：场景中至少调动两种感官。视觉（"看到……"）、听觉（"听到……"）、嗅觉（"闻到……"）、触觉（"摸到……"）、味觉（"尝到……"）。但不要求全部出现——自然地使用1-2种即可。

**镜头由远及近**：先交代场景的全貌（"厨房里热气腾腾"），再聚焦到细节（"灶台上的砂锅咕嘟咕嘟响着，盖子边沿冒着白气"）。这种手法让读者有"走进"画面的感觉。

### 3. 人物刻画

叙事散文的人物刻画靠的是"行动"和"细节"，而不是"评价"。

**用动作塑造性格**（参考 19728 写母亲）：
> "母亲撑着一把天蓝色的伞，微弓着背，缓缓地朝回走。她的腋下夹着一把绿伞，那是为我准备的。"

没有一句"母亲很爱我"，但读者的感受已经在那里了。

**用细节代替心理描写**（参考 19448 写父亲）：
不要写"父亲内心很复杂"，而是写具体的行为：
> "他在客厅里坐了很久，烟灰缸里多了几个烟头。我经过的时候，他抬头看了我一眼，又低下去了。"

**人物对话的运用**：叙事散文中的人物对话应该是"有动作的"——配合动作、神态或场景。单独的人物对话缺乏画面感。

| 避免 | 推荐 |
|---|---|
| "他问：'你去不去？'我说：'不去。'" | "他从门缝里探进半个身子，问：'你去不去？'我没抬头，说：'不去。'" |

**侧面刻画**（参考 24725）：通过他人反应来刻画未直接出场的人物。文中没有直接写那位母亲的性格，但通过全班同学的起哄、儿子的瑟缩，读者自己拼出了一个形象。

### 4. 夹叙夹议

叙事散文和纯小说的根本区别在于"议论"——叙事散文允许作者在叙事过程中发表看法，但议论的方式有讲究。

**议论的时机**：不要在叙事的紧张时刻插入议论。打断情节会让人反感。议论应该在叙事的一个段落自然收束后再出现。

**议论的长度**：一段精彩的叙事之后，一句到三句议论足矣。长篇议论会冲淡叙事的力量。

**议论的来源**：议论必须来自叙事本身，是对叙事的提炼而非外加。参考 24725 的写法——在叙述完同学的故事之后，自然引出"世界上不存在合适的母爱"。这个结论是从前面的叙事中生长出来的。

| 好例子（叙事→议论的自然过渡） |
|---|
| "她一路把龙眼攥在掌心，想着带给儿子……那时，我的眼前蓦然闪现出春雪中妈妈为我送伞的情景。母爱就像伞，把阴晦留给自己，而把晴朗留给儿女。"（19728） |

## 叙事散文与抒情散文的区别

本 skill（叙事散文）与 `skill-lyrical-prose.md`（抒情散文）互补但不重叠：

| 维度 | 叙事散文 | 抒情散文 |
|---|---|---|
| 核心驱动力 | 叙事线索——"发生了什么" | 情感氛围——"感受到了什么" |
| 结构重心 | 事件的发展、转折、收束 | 物象的堆叠、情感的递进 |
| 人物作用 | 人物是推动叙事的行动者 | 人物是承载情感的符号 |
| 时间处理 | 必须有清晰的时间线 | 时间感往往模糊或循环 |
| 议论方式 | 从叙事中自然生长，夹叙夹议 | 以景寓情，让细节替自己说话 |
| 字数范围 | 800-1200字 | 600-1000字 |

**选择原则**：如果有"一个完整的故事"可以讲（有清晰的起承转合、有人物之间的互动、有时间跨度），选择叙事散文。如果只是"一种情绪、一段印象、一个物件引发的感受"，选择抒情散文。

## 风格特征总结

| 特征 | 说明 |
|---|---|
| 叙事线索 | 有明确的"发生了什么"的故事线，有起承转合，有清晰的时间推进 |
| 人物细节 | 通过动作、对话、神态塑造人物，不贴标签，不给评价 |
| 画面感 | 每个关键情节都有场景支撑，读者能"看到"发生了什么 |
| 夹叙夹议 | 叙事为主体，议论为点缀；议论从叙事中生长，不外加不硬贴 |
| 语言风格 | 平实、有节奏感，句式长短交替；不过分追求"美文"效果，以准确表达叙事为首要目标 |
| 结构完整性 | 有开头有结尾，时间线清晰，事件发展有逻辑链条 |

## 输出约束

- **字数**：800-1200 字（中文）
- **署名格式**：文末空一行，右对齐署名，格式为 `文/XXX`（使用调用时指定的虚构作者名；如未指定，使用默认作者名"佚名"）
- **不允许**：没有叙事线索的流水账、直接说教、说理大于叙事的议论文体、政治议论
- **必须**：有一个完整的叙事线索（有开始有结束）、至少两个场景画面描写、人物通过动作和语言而非评价来塑造、结尾不落说教落余韵
- **时间线**：必须让读者清楚知道叙事的每个节点处于什么时间

## 检索策略

写作前需参考类似主题的范文，通过以下 API 检索：

```bash
# 1. 按关键词搜索叙事散文类范文
curl "https://<your-magazine-api>.workers.dev/search?q=父亲+沉默+背影+叙事&top_k=5"

# 2. 已知 ID 直接读取全文
curl "https://<your-magazine-api>.workers.dev/article/19728"
curl "https://<your-magazine-api>.workers.dev/article/24725"
curl "https://<your-magazine-api>.workers.dev/article/19448"
curl "https://<your-magazine-api>.workers.dev/article/225"

# 3. 按叙事类型搜索
# 成长叙事: curl "https://<your-magazine-api>.workers.dev/search?q=童年+成长+回忆+故事&top_k=5"
# 人物叙事: curl "https://<your-magazine-api>.workers.dev/search?q=母亲+父亲+一件小事&top_k=5"
# 时代叙事: curl "https://<your-magazine-api>.workers.dev/search?q=这些那年+以前+现在&top_k=5"
```

**搜索关键词建议**：
- 与叙事场景相关的关键词（如"火车站+送别"、"过年+回家+细节"）
- 与人物关系相关的关键词（如"父亲+沉默+背影"、"母亲+做饭+往事"）
- 与时间跨度相关的关键词（如"童年+长大+改变"、"以前+现在+不同"）
- 可参考标签体系中"展开方式=时间线式"、"叙事视角=第一人称"的组合，筛选出叙事性强而非纯抒情的文章

**注意**：叙事散文学的是"讲故事的节奏"——注意分析范文在什么时候加速叙事（用短句、快速推进情节），什么时候放慢（用场景描写、细节堆叠拉长时间感）。这种节奏控制是叙事散文的核心技法，比主题匹配更重要。

## 示例

### 示例 1

**用户输入**：
```
/叙事散文 第一次送父亲去火车站
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://<your-magazine-api>.workers.dev/search?q=父亲+送别+火车站+沉默&top_k=3"` 和 `curl "https://<your-magazine-api>.workers.dev/search?q=第一次+离别+细节&top_k=3"`。读取 ID 19448 学习"父亲为什么沉默"的叙事方式和人物刻画手法。读取 ID 19728 学习场景描写和时间线控制。

2. **确定结构**：
   - 开头（倒叙）："那年秋天我十八岁，第一次出远门上学。父亲坚持要送我到火车站。"
   - 展开：到了车站才发现车票时间搞错了，要等四个小时（叙事开端，制造紧张感）→ 父亲在候车室坐立不安，反复整理行李（人物动作刻画，通过细节写父亲的焦虑）→ 他跑去给我买了一份盒饭和一瓶水，回来的时候盒饭还热着（场景描写，推进叙事）→ 终于到了检票口，父亲把手里剩下的钱全塞给我（叙事转折点）
   - 议论过渡：写"他什么也没说，从头到尾几乎没说什么话。但那些动作，比任何话都重。"
   - 结尾（回到当下）：现在每次去火车站，都会想起那盒饭的热气。父亲依然不爱说话。
   - 时间线控制：用"那年"→"四个小时"→"终于"→"现在"建立清晰的时序

3. **输出**：一篇 800-1000 字的叙事散文，署名 `文/XXX`，时间线清晰，有至少两个场景画面（候车室+检票口），人物通过动作塑造，夹叙夹议控制在三处以内。

### 示例 2

**用户输入**：
```
/叙事散文 那个总请我吃早餐的室友
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://<your-magazine-api>.workers.dev/search?q=室友+朋友+青春+往事&top_k=3"` 和 `curl "https://<your-magazine-api>.workers.dev/search?q=大学+友情+细节&top_k=3"`。读取 ID 225 学习如何用时间线串联不同阶段的人和事。读取 ID 24725 学习从具体小事切入、层层展开的叙事方式。

2. **确定结构**：
   - 开头（场景式）：大学宿舍，每天早上那个室友都会多买一份早餐放在我桌上——明明我闹钟响了他也没醒，可他总是比我早起
   - 展开：写第一个学期，我以为是巧合（叙事开端）→ 第二学期发现不是巧合，他是故意多买一份，因为我总睡过头来不及吃早饭（叙事发展）→ 写这位室友的日常：来自农村，话不多，成绩中等，但从来不让人难堪（人物刻画，用细节拼出形象）→ 一个转折事件：寒假过后他辍学了，家里供不起（叙事转折）
   - 议论过渡："这么多年过去，吃过很多顿饭，但没有一顿比得上那个冬天早上还温着的包子和豆浆。"
   - 结尾（余韵）：不知道他现在过得好不好。但我知道，这个世上有人曾经用买早饭的方式，沉默地照顾过另一个人的自尊。
   - 时间线：大一上学期 → 大一下学期 → 寒假 → 多年以后的现在

3. **输出**：一篇 800-1200 字的叙事散文，署名 `文/XXX`，有清晰的时间推进和事件转折，人物通过"买早饭"这一核心动作贯穿塑造，结尾回到当下但不煽情，让温度留在叙事本身。

## 写作检查清单

写作完成后逐项自查：

- [ ] 是否有一个完整的叙事线索（有开始、发展、转折、结束）？
- [ ] 时间线是否清晰可辨（读者能否说出"这事发生在什么时候"）？
- [ ] 每个关键情节是否有场景画面支撑？
- [ ] 人物是否通过动作/对话塑造，而非直接评价？
- [ ] 议论是否从叙事中自然生长（不多于三处，每处不超过三句）？
- [ ] 结尾是否避免了说教总结？
- [ ] 全文是否控制在 800-1200 字？
- [ ] 是否加了署名（`文/XXX`）？
- [ ] 是否能回答"然后呢？"——每一段都在推动叙事？

以上检查项全部通过，即可输出。
