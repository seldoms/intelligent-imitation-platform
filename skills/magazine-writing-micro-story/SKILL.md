## 能力

以"在有限篇幅内讲一个值得讲的故事"为核心理念，在 600-1000 字的严格约束下，快速建立人物与场景、推进矛盾、制造转折、收束留白。微型故事不同于抒情散文（不依赖物象寄托情感）和叙事散文（不夹叙夹议）——它的核心是"故事本身"，一切服务于情节的起承转合。人物在行动中塑造，矛盾在对话中推进，转折在细节中埋伏，余味在留白中生长。

## 调用方式

```
/微型故事 <主题或素材>
```

## 输入示例

```
/微型故事 一场迟到了二十年的道歉
/微型故事 她在山顶等到了日出
/微型故事 一个从不收礼的处长最后收下的那包烟
```

### 范文核心技法提取

**24924（母爱的视角）**：从"视角"这个小切口入手，全文几乎只有一个场景、一个动作（母亲如何"看"孩子），但通过层层递进的细节描写，人物的内心世界完整浮现。结尾三句话内完成情感反转——这种"前平后陡"的结构是微型故事最常用的节奏模式。

**1261**：人物在开头第一段就亮出核心矛盾，没有任何铺垫性描写。"直接开场"的技巧——读者被一个悬念或一句对话直接拉入故事，然后在向前推进中慢慢了解背景。

**26594**：采用"设伏-引爆"结构。前三分之二的篇幅精心埋设看似无关的细节，在后三分之一处用一个关键信息串联所有伏笔，让读者产生"原来如此"的顿悟感。

**15762**：故事在情感最饱满、读者最想知道"然后呢"的时候收尾。不交代结局，不给解释，让读者在故事结束后自行回味。这种"断在最高处"的勇气是微型故事区别于长故事的重要特征。

**16657**：场景固定（一个房间、一张桌子、两个人的对话），时间跨度短（一顿饭、一个下午），但情节密度极高。人物的每一个动作——端杯子的方式、看表的频率、停顿的长短——都在叙事。

## 结构模板

### 第一部分：人物出场 + 矛盾建立（150-250 字）

**写法指导**：微型故事没有"预热"的时间。第一段必须同时完成两件事：让读者知道"这是一个什么样的人"和"他面临什么问题"。不要用"张三是……"的第三人称介绍；让人物的动作和对话自己"说"出自己是谁。

```
可选开场方式：
- 对话开场：以一个核心对话句直接切入，"'你真的要去？'她把车钥匙攥在手里，指节发白。"
- 动作开场：人物正在做一件有冲突感的事情，"他站在病房门口，手举起来停了五秒，还是没有敲下去。"
- 悬念开场：抛出一个让读者立刻想问"为什么"的事实，"老李在退休当天，被纪委带走了。他等这一天，等了三十年。"
```

**核心原则**：开场段落中至少包含以下三项中的两项：
1. 一个可辨识的人物特征（职业/身份/性格特质的一鳞半爪）
2. 一个明确的矛盾或困境（人物面临的选择、冲突或压力）
3. 一个让读者想知道"然后呢"的钩子

### 第二部分：矛盾发展 + 对话推进（200-400 字）

**写法指导**：这是故事的主体。微型故事没有第二幕和第三幕的区分，第二段到第三段要在最短字数内完成"矛盾升级"。

**关键技法：让对话承担叙事功能**

微型故事的推进效率要求每句对话至少要完成以下功能之一：
- **透露信息**（"你哥昨晚来过了。""不可能，他两年前就——"）
- **推进关系**（"我还以为你不来了。""我也不想来。"）
- **制造紧张**（"你确定要这么做？""我确定。"然后她低下头，声音小了半度，"只是没想到会这么难。"）
- **埋设伏笔**（"他走之前说了一句话，我没听懂。他说：'那个花园，明年就不会再开了。'"）

**场景手法的运用**：
- 在关键对话前后插入一个"动作注脚"——一个微妙的人物动作或环境细节，增加层次感（参考 16657）
- 对话段落中至少有一个"沉默"时刻——人物停下来做什么，而不是一直说
- 不宜使用过多的场景描写，每 200 字最多一处场景画面，其余留给对话和动作

### 第三部分：转折 / 反转（100-200 字）

**写法指导**：微型故事的灵魂在"转折"。没有转折或反转的微型故事只是短文章，不是故事。

**四种常用反转类型**：

1. **信息逆转**：读者一直以为的"事实"被一个新信息推翻。前面所有的细节都在这一刻被重新定义（参考 26594）。
2. **身份揭示**：一个角色的真实身份或真实关系在结尾揭晓。"那个一直沉默的看门人，其实是当年事故中唯一的幸存者。"
3. **动机揭露**：前文展示的行为没有变，但背后的动机被揭示——同样的行为，换个动机就是完全不同的故事。"他把存折放在我枕头底下，不是因为慷慨，是因为他觉得自己活不了多久了。"
4. **视角转换**：从"我"的视角突然切换到"他"的视角，或者第三人称叙事突然揭示另一个角色的内心世界。

**关键**：转折必须有"前文伏笔"支撑。一个成功的反转让读者"惊讶但觉得合理"；一个失败的反转让读者觉得"你在耍我"。

好反转的检查方法：在反转之前，故事中至少有一个看似无关的细节（一个动作、一句话、一个物件）可以被重新解读为伏笔。

### 第四部分：收束 / 留白结尾（100-150 字）

**写法指导**：微型故事的结尾最忌"说清楚"。结尾应该：

- **断在最高处**：在情感最饱满的时刻收住，不给"然后呢"的答案（参考 15762）
- **用画面收尾**：不说"他原谅了她"，而是写"他把那封信放回抽屉，没有拆开"
- **留空间**：结尾应该像一个省略号，不是句号。故事结束了，但读者心里的故事才刚刚开始

禁止使用的结尾方式：
- "通过这件事……"式的总结评价
- "他后来终于明白……"式的训诫口吻
- "这个故事告诉我们……"式的寓言式总结
- 用大段内心独白解释"人物在想什么"

## 技法要点

### 1. 快速建立人物

微型故事没有 500 字的篇幅给人物做背景介绍。需要在 150 字之内让读者对人物形成清晰的印象。

**三笔法**：用三个细节写活一个人物。

| 层次 | 内容 | 示例 |
|---|---|---|
| 第一笔 | 一个外部特征（衣着/动作/神态） | "他的白衬衫永远扎进裤腰里，袖口的扣子扣到最上面一颗。" |
| 第二笔 | 一句能透露性格的对话 | "'按规矩来。'这是他说的最多的一句。" |
| 第三笔 | 一个让读者记住的独特行为 | "每次离开办公室，他都会回头看一眼插座拔了没有。" |

三笔之后，读者应该能"看见"这个人，并对他产生某种感情（喜欢、讨厌、同情、好奇）。

**人物标签**：给人物一个鲜明的"识别特征"贯穿全文。不是外貌描写，而是一个独特的行为模式或语言习惯。参考 24924 中母亲"看"的方式。

### 2. 对话推进叙事

微型故事的对话不应该是"两个人在聊天"，而应该是"两个人在通过语言做事情"。

**潜台词**：人物的对话要有"水面之下的冰山"。写出来的话是冰山的一角，没有说出来的部分才是真正重要的。

> 错误的对话：
> "你很难过吧？""是的，我很难过。"
>
> 好的对话（有潜台词）：
> "要下雨了。""嗯。"
> "带伞了吗。""没有。"
> "我的给你。""那你呢？"
> "我不远。"

对话中的每一句都要有"话外之意"。上面对话表面上在谈天气和伞，实际上在写"一个想靠近、一个想保持距离"的微妙关系。

**对话节奏控制**：
- 紧张时刻：使用短促的对话句，一人一句快速交替
- 抒情时刻：在对话中加入动作描写或停顿，放慢节奏
- 转折时刻：在一句关键对话前后留足空白——"沉默了很长时间"之后再接下一句

### 3. 留白结尾

微型故事的结尾是"含"着的，不是"吐"出来的。好结尾的标准：

1. **故事停止了，但读者的思考没有停止**——读者在合上故事后还在琢磨
2. **情感有落脚点**——读者被故事打动，但不一定能说清楚是"哪一句话打动了你"
3. **有余韵**——结尾的画面或对话会在读者脑中持续回响

**检查结尾的方法**：
- 在写完后问自己：如果把最后一段删掉，故事会变差吗？会——说明结尾不是"为了收尾而收尾"的冗余。
- 如果再写一段补充说明，会让故事更好吗？不会——说明结尾已经完整。

### 4. 让故事本身说话

微型故事不需要"调度"读者的情感。不要告诉读者"这是一个感人的故事"，也不要告诉读者"这件事很让人难过"。让故事里的细节、对话、动作自己去影响读者。

| 避免 | 推荐 |
|---|---|
| "那一刻他无比后悔" | "他坐下来，把脸埋进手里，很久没有抬头。" |
| "她是一个善良的人" | "她每天早起半小时，把楼道里邻居的垃圾袋顺手带下去。" |
| "这是一个令人心碎的转折" | 直接把转折事实写出来，不加修饰语 |

**金律**：如果你发现自己用了一个情感形容词（"痛苦地""悲伤地""欣慰地"），就重写这句话。去掉形容词，让动作本身说话。

## 风格特征总结

| 特征 | 说明 |
|---|---|
| 开头 | 第一句话就入题，不做铺垫，直接进入核心矛盾或冲突 |
| 人物 | 单一核心人物贯穿全文，最多 2-3 个人物；用"三笔法"150字内建立清晰形象 |
| 叙事驱动 | 对话推进为主，场景描写为辅；每句对话承担叙事功能 |
| 转折 | 必须有；前文设伏，结尾引爆；让读者惊讶但觉得合理 |
| 结尾 | 断在最高处，留白不解释；不总结、不升华、不训诫 |
| 字数 | 600-1000 字，每个部分分配严格：开头150-250 + 正文200-400 + 转折100-200 + 结尾100-150 |
| 语言风格 | 简洁、有节奏感；白描为主，少用修饰语；形容词克制使用——能用动词的地方不用形容词 |

## 微型故事 vs 抒情散文 vs 叙事散文

本 skill（微型故事写手）与 `skill-lyrical-prose.md`（抒情散文）、`skill-narrative-prose.md`（叙事散文）互补但不重叠：

| 维度 | 微型故事 | 抒情散文 | 叙事散文 |
|---|---|---|---|
| 核心驱动力 | 情节——故事的起承转合 | 情感氛围——感受到了什么 | 叙事线索——发生了什么 |
| 结构重心 | 矛盾-转折-收束 | 物象堆叠-情感递进 | 事件发展-夹叙夹议 |
| 人物作用 | 推动情节的行动者 | 承载情感的符号 | 叙事中的见证者 |
| 对话使用 | 核心手段，推动叙事和揭示信息 | 很少使用 | 作为人物刻画的辅助 |
| 转折要求 | 必须有反转或顿悟 | 不需要 | 可以有但不必须 |
| 结尾 | 留白，在最高处收住 | 留白，回到起点多一层意味 | 余韵，回到当下 |
| 字数 | 600-1000 字 | 600-1000 字 | 800-1200 字 |

**选择原则**：如果你有一个"完整的故事"——有人物、有矛盾、有转折——选微型故事。如果你只有"一种情绪、一段印象"——选抒情散文。如果你有"一段完整的人生经历"要带着感悟去叙述——选叙事散文。

## 输出约束

- **字数**：600-1000 字（中文）
- **署名格式**：文末空一行，右对齐署名，格式为 `文/XXX`（使用调用时指定的虚构作者名；如未指定，使用默认作者名"佚名"）
- **不允许**：空发议论、直接抒情、说教总结、"通过这个故事我们学到"式结尾、政治议论
- **必须**：在第一段内完成人物出场和矛盾建立、至少一段有潜台词的对话、一个前置伏笔并完成反转、结尾断在最高处而非把话说尽
- **人物**：核心人物不超过 2 个（含"我"）
- **场景**：场景不超过 3 个；推荐 1-2 个场景内完成全部故事（参考 16657）

**搜索关键词建议**：
- 与故事类型相关的关键词（"短篇+亲情+反转"、"陌生人+帮助+转折"）
- 与核心技法相关的关键词（"对话+推进"、"留白+结尾"、"一句话+反转"）
- 与人物关系相关的关键词（"父子+矛盾+和解"、"母女+误会+真相"）
- 可参考标签体系中"展开方式=时间线式"+"结尾技巧=留白式"的组合，筛选出故事性强且有反转的作品

**学习重点**：
- 微型故事的学习重点不在于"主题匹配"，而在于"结构学习"——找到一篇结构精妙的微型故事（无论什么主题），分析它"用了多少字建立人物"、"在哪句话埋了伏笔"、"反转出现在什么位置"、"结尾如何收束"，比匹配到同主题但结构松散的文章更有价值
- 优先搜索那些标签包含"结尾技巧=留白式"或"修辞手法=对比"的文章，它们更可能是有反转的微型故事

## 示例

### 示例 1

**用户输入**：
```
/微型故事 一封写了三十年的信
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://magazine-api.seldomsemail.workers.dev/search?q=信+迟到的道歉+等待&top_k=3"` 和 `curl "https://magazine-api.seldomsemail.workers.dev/search?q=短篇+反转+留白&top_k=3"`。读取 ID 26594 学习"设伏-引爆"结构，读取 ID 15762 学习"断在最高处"的结尾方式。

2. **确定结构**：
   - 开头（200字，对话/动作开场）：一个男人在整理父亲遗物时发现一封信，收件人是一位远在异地的老战友。"三十年""从未寄出"——两个信息建立悬念，读者会问"信里写了什么？为什么没寄出？"
   - 展开（350字，对话推动叙事）：他在犹豫是否要寄出这封信。他的母亲在一旁看着，说了几句看似无关的话——"你爸那年在部队，回来之后像变了一个人"（潜台词：信里藏着一段他不知道的往事）→ 他开始回想父亲生前的沉默和某种愧疚感（伏笔铺垫）
   - 转折（150字，信息逆转）：他打开信，发现信里写的不是道歉，而是一句"当年那个命令是我下的"——读者和他同时明白，这不是一封感情信，而是一个背负了三十分年秘密的人想要在死前还清最后一笔账
   - 结尾（100字，留白画面）：他拿着信站在邮筒前。母亲在身后说："寄出去吧，他来不来得及收到，是他的事。寄不寄，是你的事。"他不确定她知不知道信里写了什么。他伸手把信塞了进去。
   - 伏笔设计：母亲那句"你爸那年在部队，回来之后像变了一个人"——在第一遍读时像是一句关于父亲的寻常感慨，在反转后重新理解，才意识到母亲隐约知道那件事

3. **输出**：一篇 800 字左右的微型故事，署名 `文/XXX`，开头即建立人物和悬念，对话承担全部叙事功能，有两处伏笔（"从未寄出的信"+母亲若有所指的话），结尾在"信被塞进邮筒"的画面镜头停住，不交代老战友是否收到、是否有回信。

### 示例 2

**用户输入**：
```
/微型故事 她终于说了真话
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://magazine-api.seldomsemail.workers.dev/search?q=职场+同事+秘密+反转&top_k=3"` 和 `curl "https://magazine-api.seldomsemail.workers.dev/search?q=对话+冲突+真实身份&top_k=3"`。读取 ID 16657 学习"固定场景中依靠对话推进故事"的技法，读取 ID 1261 学习"第一段就建立矛盾"的节奏。

2. **确定结构**：
   - 开头（180字，对话开场）："你为什么要帮我？"她看着对面的男人，语气里没有感激，只有警惕。他说："因为我也在帮我自己。"这句让对方（和读者）立刻警觉——这不是一个无私的帮助，背后另有动机。
   - 展开（300字，单一场景+对话）：在公司楼下的咖啡厅，两人面对面坐着。男人刚帮她在项目评审会上挡了一刀。她不相信有人会无缘无故冒险帮一个只认识三个月的新人。她逐一追问他帮助她的原因，他逐一避开正面回答（对话的潜台词：一个有秘密的人在掩盖什么；一个警惕的人在试图挖出真相）→ 场面一度陷入沉默，她准备起身离开（叙事中的"危机时刻"）
   - 转折（180字，身份揭示 + 动机揭露）：她站起来的时候说了一句话——"如果你和两年前那件事有关，我会辞职。"整个环境安静下来。他看着她，说："我就是那个被你举报的人。"她的脸色变了——她认出了他。
   - 伏笔设计：前半段他始终在回避回答"为什么帮她"，但回答的方式闪闪烁烁，像个有秘密的人。读者可能会以为他动了感情，或者另有所图。揭晓时所有反常的回避都有了新的解释。
   - 结尾（120字，留白断点）：她说："你该恨我。""我试过。"他把咖啡杯放回桌上，伸出一只手——像刚刚认识的人一样。"我叫陈远。重新认识一下。"她看着那只手，过了很久，才把自己的手伸出去。
   - 结尾停留在"两只手即将握住"的画面。读者不知道她有没有握上去，不知道他们之后是敌是友——但画面的张力已经够了，读者会自己完成"和解是否达成了"的想象。

3. **输出**：一篇 780 字左右的微型故事，署名 `文/XXX`，单一场景、两位人物，全部情节通过对话和细微的动作描写推进，结尾定格在有悬念的画面上，留白让读者自行完成情感的收束。

## 写作检查清单

写作完成后逐项自查：

- [ ] 第一段是否同时完成了"人物出场"和"矛盾建立"？
- [ ] 人物是否在 150 字内建立了至少三个记忆点（三笔法）？
- [ ] 情节是否通过对话推进（非纯叙述推进）？
- [ ] 是否有至少一段含潜台词的对话？
- [ ] 反转/转折是否在故事中有前置伏笔？
- [ ] 读第二次时，是否能发现第一次读时忽略掉的伏笔线索？
- [ ] 是否避免了任何"人物在想什么"的直接心理描写？
- [ ] 结尾是否断在最精彩的地方，没有画蛇添足的解释？
- [ ] 是否有任何"通过这件事……""这个故事告诉我们……"式的说教？
- [ ] 全文是否控制在 600-1000 字？
- [ ] 场景是否不超过 3 个，推荐不超过 2 个？
- [ ] 是否加了署名（`文/XXX`）？

以上检查项全部通过，即可输出。
