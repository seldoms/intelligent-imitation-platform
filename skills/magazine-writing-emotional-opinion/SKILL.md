## 能力

以"观点驱动、故事支撑"为核心理念，围绕一个情感话题提出独到见解，用真实感人的故事和场景细节作为论据，在层层推进中亮出观点的"反向"面——大多数人习以为常的看法背后，存在另一种更值得被看见的真相。不同于抒情散文的"以物寄情"和叙事散文的"以事动人"，情感观点文的核心是"以理服情"——用理性框架组织情感素材，让读者在读完之后产生"原来是这样"的认知转变。

## 调用方式

```
/情感观点 <话题或论点>
```

## 输入示例

```
/情感观点 为什么说"为你好"是最伤人的爱
/情感观点 孝顺不是顺从——谈当代亲子关系中的边界
/情感观点 我们为什么越来越不敢认真对待爱情
/情感观点 友情里的"欠债感"正在摧毁真正的友谊
```

### 范文核心技法提取

**24725（这种母爱）**：观点先于故事——文章开头就抛出"这种母爱让我感到难堪"的明确态度。全文以"一件事引发一个思考"的结构推进，每一个故事片段都嵌入一个明确的观点判断（"但我很快发现自己的错误"）。最关键的是"反向转折"：先写自己对这种母爱的不认同，再转折到理解，这种"先立靶子再推翻"的手法赋予观点以层次感。

**19448（父亲为什么沉默）**：用"反问"作为观点推进器——"父亲是真的不爱说话吗？""他为什么不试着沟通？"每一个故事段落都以一个潜藏的反问收尾，迫使读者自己思考。观点不是在文章开头一次性给出，而是在每段结尾逐层积累，最后汇成一个完整的判断。

**24924（母爱的视角）**：用"视角转换"替代直接论证——不谈"母爱伟大"这种抽象观点，而是通过"换一个角度去看同一个动作"，让读者自动得出新的结论。核心技法：把一个日常行为放在新的参照系中，让它呈现出完全不同的意义。

**26594（父亲的裸捐与我的未来）**：情感冲突驱动观点形成——文章的观点是在一个具体的人生困境中生长出来的（父亲要捐掉全部财产），而不是预先设定好的。冲突越大，观点形成的张力越强，最终的"理解"也越有说服力。

**19728（龙眼与伞）**：用"双线镜像"支撑观点——两个看似独立的故事（母亲送伞被拒、青岛友人攥着龙眼去看儿子）在同一主题下并置，互相解释、彼此照亮。不直接说"母爱是无条件的"，而是让两个故事的对比自己去说。

## 结构模板

### 开头（150-200字）：用共情场景引出核心问题

**写法指导**：情感观点文的开头不能像抒情散文一样只写物件，也不能像叙事散文一样只讲故事。开头要完成三件事：
1. 制造代入感——让读者觉得"这事跟我有关"
2. 提出一个大家司空见惯但极少深想的现象
3. 暗示这个现象背后"可能没那么简单"

```
可选开场方式：
- 场景+问题式：先写一个日常场景，然后提出一个让读者一愣的问题
  "母亲又在众人面前给我喂食了。同学在笑，我在躲，她却浑然不觉。爱一个人，真的可以不顾对方的感受吗？"
- 现象+反转式：描述一个普遍现象，然后指出其中被忽略的盲区
  "我们都说父爱如山，沉默稳重。但有没有想过——山的沉默，也许不是因为厚重，而是因为不会表达？"
- 故事+悬念式：以一个简短的故事片段开头，留一个悬念引向观点
  "父亲决定把所有积蓄捐出去那天，我第一次对他感到愤怒。不是因为他做错了什么，而是因为我觉得——他做对了，唯独对我做错了。"
```

示例开头（参考 24725）：
> "高中同桌李明的母亲，每隔两周就会来学校看他一次。每次来都带着一大袋吃的，然后在食堂当着所有人的面，把饭菜一口一口喂到李明嘴里。十七岁的男生，在众目睽睽之下被妈妈喂饭——每一次，李明都低着头，脸颊通红。"

**注意**：开头不要直接讲道理。不要以"在现实生活中，我们常常会遇到……"开头。让读者先"看见"一个具体的人、一个具体的场景，然后才引出观点。

### 展开（400-600字）：层层推进，2-3个事例支撑核心观点

**写法指导**：展开部分是观点的"论证链"。每个段落都是一个独立的论证环节，不能随意堆叠。

**第一层（第一个事例/角度）**：从开头的场景延伸出去，给出第一个观点判断。这是文章立论的基础——让读者初步认同"哦，作者说的是这么回事"。

> 示例（参考 24725）：先写李明母亲喂食时的具体画面（事件），再写李明的反应和同学的起哄（他人的视角），最后抛出第一个观点——"母亲的这种爱，从一开始就没有把儿子当成一个独立的人。"

**第二层（第二个事例/角度，递进或对比）**：这一层要与第一层形成递进关系。要么拉长时间（小时候→现在），要么转换人物（观察者→亲历者），要么拓宽视野（个人→社会现象）。

> 示例：从李明延伸到自己的母亲，或者从"喂食"延伸到"以爱为名的控制"——把话题从一个个案上升到一种普遍的情感困境。

**第三层（第三个角度或反面案例）**：这一层是"观点反向"的关键段落。要主动引入与前面论点相矛盾的材料，然后再把它转化为对核心观点的深化。

> 示例：写李明母亲每次喂完饭后的表情——"她满足地笑了，那笑容里没有一丝控制的快感，只有纯粹的、笨拙的开心。"这个细节与前面的"控制"判断形成矛盾，但恰恰是这个矛盾让观点变得复杂而真实。

**关键原则**：
- 每个段落的开头要用"观点句"建立论点方向，然后用故事/场景作为论据
- 段与段之间要用逻辑连词衔接（"但""然而""其实""可是""更值得注意的是"）
- 不要写与核心观点无关的故事——每个事例都必须是论证的一环
- 感情的"温度"和观点的"锐度"要平衡：论证不能变成吵架，情感不能变成说教

### 转折（100-200字）：指出常见误解或反面

**写法指导**：转折是整个情感观点文的"药引"。没有转折的文章只是普通的情感散文，有了转折才成为"观点文"。转折的作用是：指出大多数人（包括开头的"我"）对这个问题的看法是片面的、不完整的。

转折的核心是"换一个角度"：
- 从子女的角度看，母亲的关注是控制；但从母亲的角度看，那只是她唯一懂得的爱的表达方式（24725的转折）
- 从孩子的角度看，父亲的沉默是冷漠；但从父亲的角度看，沉默是他最不愿意使用的武器（19448的转折）
- 从被捐赠者的角度看，父亲的裸捐是背叛；但从一个更大的生命尺度看，那是一种超越血缘的价值观传递（26594的转折）

转折段落最常见的写法结构：
1. "但后来我想明白了……" 或 "问题是，这样的理解就够了吗？"
2. 用"如果换一个角度看"或"也许不是……而是……"句式引出新的解释
3. 用一个细节或场景作为新解释的论据（第二段开头提到的"母亲喂饭后的表情"）

**规则**：转折必须在论据上有新支撑，不能只是"换了个说法"。一个新的细节=有效的转折；一句"其实换个角度想"=无效的转折。

### 结尾（100-150字）：情感升华或行动号召，温暖有力

**写法指导**：结尾是整篇文章情感的收束点。观点文不能像抒情散文那样完全"藏"着情感——它需要在结尾处给出一个明确的"落脚点"，让读者带着一种新的认识离开。

```
可选结尾方式：
- 观点回环式：回到开头的场景或故事，但赋予它全新的解释
- 行动号召式：从"理解"延伸到"行动"——"所以，下一次……也许我们应该……"
- 情感共鸣式：用一句有温度的话收束，让读者既接受了观点，又被情感触动
```

示例结尾（参考 24725 的技法）：
> "世界上存在恰到好处的母爱吗？我想不存在。每一份母爱都带着自己时代与认知的烙印，或粗糙、或笨拙、或令人窒息。但我们不能因为它的不完美就否认它的存在。爱从来不是光洁的，它有裂纹、有棱角。我们要做的，也许不是苛责它的形状，而是学会辨认藏在粗粝表面下的那一颗真心。"

**禁止**：
- 以"综上所述……"式的论文结论收尾
- 以"你学会了吗？"式的说教收尾
- 升华到连文章本身都没有铺垫的宏观道理
- 用空洞强调（"真的！"、"太重要了！"）来增加力度

## 技法要点

### 1. 先讲一个让人"代入"的故事再出观点

情感观点文最大的陷阱是"观点先行"——开头就抛出一个论断，然后用故事去证明它。正确的顺序是：先用一个让读者产生"这说的就是我"感觉的具体场景，让读者产生代入感，然后再自然引出观点。

| 错误的做法 | 正确的做法 |
|---|---|
| "母爱有时候也是一种负担。"（先观点） | "高中同桌李明的母亲，每两周来一次学校，在食堂当着所有人的面喂他吃饭——那一刻，我在别人的尴尬里看到了自己的母亲。"（先故事） |
| "父爱的失语值得深思。"（先观点） | "我父亲一辈子对我说的话，加起来可能没有他抽过的烟多。但他会在我起床前把自行车擦干净、链条上满油。"（先故事） |

**规则**：在抛出任何观点判断之前，至少写满一个完整的场景段落（3-5句），让读者先"进入"情境。

### 2. 观点要有"反向"

情感观点文区别于普通情感散文的核心特征就是"反向"。所谓反向，不是刻意唱反调，而是揭示一个被大多数人忽略的真相层面。

**反向的类型**：
- 认知反转：大家都觉得是A，但实际是B（"大家都认为母爱是温暖的，但有时候它是令人窒息的"→"但这种窒息感恰恰说明母亲的在乎"）
- 价值重估：大家都觉得不好，但有另一种理解（"父亲沉默是不关心"→"沉默是他唯一知道的表达方式"）
- 视角转换：站在不同的位置看同一个问题（从子女→从父母，从接收者→从给予者）

**判断标准**：如果一篇文章的核心观点，任何一个普通读者"不用想就能同意"，那就没有反向。反向应该是"读完之后觉得'原来是这样'，但让我自己说却说不出"的那种认知。

### 3. 情感要真实，不煽情

情感观点文的情感应该是"沉"的，不是"飘"的。

| 避免 | 推荐 |
|---|---|
| "那一刻我的眼泪夺眶而出" | "我低着头，假装在看手机" |
| "父亲的爱是如此深沉而伟大" | "他什么也没说，只是把烟掐灭，起身去厨房给我下了碗面" |
| "她的付出让我终生难忘" | "多年后我也成了父母，才想起那天下午她的背影" |

**检验方法**：写完一段情感描写后，问自己——如果这段话出现在社交媒体上，读者是会点赞转发，还是会觉得"太刻意"？如果答案是后者，删掉重写。

### 4. 每段控制在3-5句，节奏要快

情感观点文的读者是碎片阅读者，节奏必须快。慢节奏会让读者失去耐心。

**节奏控制法则**：
- 每段不超过5句，每句不超过40字
- 长句和短句交替使用：1个长句子（15-20字描述场景）→1个短句子（5-10字抛出观点）→1个中句子（10-15字过渡）
- 避免大段的心理描写，用动作和对话替代
- 每段末尾留一个"钩子"——让读者想读下一段

### 5. 克制引用名言

引用名人名言是情感观点文常见的"偷懒"做法。可以引用，但有限制：
- 一篇文章最多引用1次名言
- 不能引用烂大街的名言（"树欲静而风不止""子欲养而亲不待"等）
- 引用必须来自文章已经建立的情感情境，不能凭空出现

### 6. 论证密度控制

情感观点文不是议论文，它的论证不能像学术文章一样严谨，也不能像散文一样松散。控制密度的方法是"3-2-1"法则：
- 每800-1000字使用3个故事/场景片段（论据）
- 每个故事之后跟2句展开分析（连接故事和观点）
- 全篇只论证1个核心观点

## 情感观点文与抒情散文、叙事散文的区别

本 skill（情感观点文）与 `skill-lyrical-prose.md`（抒情散文）、`skill-narrative-prose.md`（叙事散文）互补但不重叠：

| 维度 | 情感观点文 | 抒情散文 | 叙事散文 |
|---|---|---|---|
| 核心驱动力 | 观点——"我发现了什么不一样" | 氛围——"感受到了什么" | 故事——"发生了什么" |
| 结构重心 | 论证链：观点→事例→反向→升华 | 情感堆叠：物→忆→味 | 事件推进：开始→发展→转折→收束 |
| 故事作用 | 作为论据支撑观点 | 作为情感的载体 | 作为叙事的主体 |
| 情感处理 | 情感在观点之后释放（先理后情） | 情感贯穿全文（以情贯文） | 情感藏在叙事中（以事含情） |
| 观点密度 | 每段都有明确的观点句 | 观点隐含在细节中 | 夹叙夹议，议论从属于叙事 |
| 结尾要求 | 温暖有力的收束（给出落脚点） | 留白、点到即止 | 余韵或回首 |
| 字数范围 | 800-1200字 | 600-1000字 | 800-1200字 |

**选择原则**：
- 如果核心是一个"观点"（你想让读者认同一个不同于常识的看法），使用情感观点文
- 如果核心是一种"情绪"（一段记忆、一种感受、一次触动），使用抒情散文
- 如果核心是一个"故事"（一件完整的事，有起承转合），使用叙事散文

## 风格特征总结

| 特征 | 说明 |
|---|---|
| 核心驱动 | 一个鲜明的"反向"观点，挑战读者的常识判断 |
| 开头方式 | 共情场景/故事引入，让读者先代入再接受观点 |
| 论证方式 | 以故事为论据，3个场景/片段支撑一个核心观点 |
| 转折设计 | 必须有一个"认知翻转"段落，揭示被忽略的真相 |
| 情感表达 | 真实克制，用细节和动作代替直接抒情 |
| 段落节奏 | 每段3-5句，长短交替，段尾设钩 |
| 结尾风格 | 温暖有力的收束，给出新的理解和行动方向 |
| 语言风格 | 平实有力，观点句清晰醒目，不追求华丽辞藻 |

## 输出约束

- **字数**：800-1200 字（中文）
- **署名格式**：文末空一行，右对齐署名，格式为 `文/XXX`（使用调用时指定的虚构作者名；如未指定，使用默认作者名"佚名"）
- **不允许**：观点先行（没有故事支撑的干巴巴的议论）、纯抒情无观点、学术论文式的论证结构、引用过度（超过1次名言）、空洞说教、政治议论
- **必须**：有一个明确的核心观点且具有"反向"特质、至少2个具体的故事/场景片段作为论据、一个认知翻转的转折段落、温暖有力的结尾收束、每段控制在3-5句

## 检索策略

写作前需参考类似主题的范文，通过以下 API 检索：

```bash
# 1. 按关键词搜索相关范文（推荐先使用语义搜索）
curl "https://magazine-api.seldomsemail.workers.dev/search?q=亲情+观点+反向&top_k=5"

# 2. 已知 ID 直接读取全文（情感观点文重点学习以下文章）

curl "https://magazine-api.seldomsemail.workers.dev/article/19448"
curl "https://magazine-api.seldomsemail.workers.dev/article/24924"
curl "https://magazine-api.seldomsemail.workers.dev/article/26594"
curl "https://magazine-api.seldomsemail.workers.dev/article/19728"

# 3. 按话题搜索
# 亲情类观点: curl "https://magazine-api.seldomsemail.workers.dev/search?q=母爱+父爱+不同看法&top_k=5"
# 友情类观点: curl "https://magazine-api.seldomsemail.workers.dev/search?q=友谊+边界+选择&top_k=5"
# 爱情类观点: curl "https://magazine-api.seldomsemail.workers.dev/search?q=爱情+婚姻+真相&top_k=5"
# 人生观点类: curl "https://magazine-api.seldomsemail.workers.dev/search?q=人生+选择+不同角度&top_k=5"
```

**搜索关键词建议**：
- 使用"观点+反向"或"不同看法"的组合搜索，更容易找到有观点翻转的文章
- 同时搜索具体话题关键词（"孝顺""控制""沉默""牺牲""边界"等）获取更多素材
- 如果搜索到的文章偏向纯抒情（缺乏观点句），尝试调整关键词为"反思""看待""理解"等带有判断性的词

**注意**：情感观点文的核心学习要点不在于主题匹配（同一主题下观点可以完全不同），而在于"论证链"的组织方式——新故事如何引出新观点，新观点又如何被下一个故事推翻和深化。阅读范文时重点分析每段开头的"观点引导句"，以及段与段之间的逻辑衔接方式。

## 示例

### 示例 1

**用户输入**：
```
/情感观点 为什么说"为你好"是最伤人的爱
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://magazine-api.seldomsemail.workers.dev/search?q=为你好+控制+爱的表达&top_k=3"`。重点读取 ID 24725（这种母爱）学习如何从"令人不适的爱"切入并完成观点翻转。同时读取 ID 19448（父亲为什么沉默）学习以"沉默"这种负面的情感表现形式反向论证爱的存在。

2. **确定结构**：
   - 开头（共情场景）：写一个日常冲突——母亲因为"为你好"强迫你做某件事，你抗拒地关门，门外的沉默
   - 第一层（第一个观点判断）："为你好"的三个字完美地绑架了所有反驳——你无法反对一个好意图，但你明明感到不舒服
   - 第二层（递进事例）：延伸到更多"为你好"的场景（选专业、找工作、催婚），指出这些行为的共同逻辑——爱你的人用你的未来压你，让你连生气的资格都被剥夺
   - 第三层（转折论点）：但"为你好"的背面，其实是另一个时代里的一种"不知所措"——他们没有更好的语言来表达"我害怕你过得不好"
   - 结尾（温暖收束）：也许我们需要的不是拒绝"为你好"，而是教会父母另一种表达关心的方式——"你开心就好"

3. **输出**：一篇 800-1000 字的情感观点文，署名 `文/XXX`，核心观点具有"反向"（"为你好"不是控制，是一种进化未完成的爱），有3个故事/场景片段支撑论证，有明确的转折段落，结尾给出行动方向。

### 示例 2

**用户输入**：
```
/情感观点 为什么越亲密的人越容易互相伤害
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://magazine-api.seldomsemail.workers.dev/search?q=亲密关系+伤害+边界&top_k=3"`。重点读取 ID 24725 学习"亲密关系中的不适感"的写法，读取 ID 26594（父亲的裸捐与我的未来）学习如何处理亲密关系中的"冲突与和解"。

2. **确定结构**：
   - 开头（故事场景）：一对情侣在餐厅吵架——起因是一句话，扩散到过去三个月的所有不满
   - 第一层（观点判断）：我们对陌生人礼貌客气，却对最亲近的人毫无保留地释放攻击性——不是因为不爱，是因为"知道对方不会走"
   - 第二层（事例递进）：延伸到亲子关系——孩子对父母说最狠的话，也是因为"安全"。越是安全的关系，越容易失去经营意识
   - 第三层（转折）：但"不会走"不等于"不需要照顾"。那些以为永远不会离开的人，也有一颗会痛的心。真正的亲密不是可以随意发泄的许可证，而是一种"我知道你会原谅我，所以我尽量不让你受伤"的自觉
   - 结尾（升华）：距离产生不了美，边界才能。与其说"因为亲近所以伤害"，不如说"因为亲近所以更需要学习好好说话"

3. **输出**：一篇 800-1200 字的情感观点文，署名 `文/XXX`，核心观点在社会常识（"亲近所以随意"）的基础上完成反向（"亲近所以更需要经营"），有2-3个具体故事场景支撑，转折段落揭示被忽略的真相（安全感需要被保护而非滥用）。

## 写作检查清单

写作完成后逐项自查：

- [ ] 是否有一个鲜明的核心观点且具有"反向"特质？（不是人云亦云）
- [ ] 开头是否先用故事/场景让读者代入，而非直接用观点句开头？
- [ ] 是否有至少2个具体的故事/场景片段作为论据？（每个论据都被观点句包裹）
- [ ] 是否有专门的转折段落，揭示大多数人的认知盲区？
- [ ] 结尾是否给出了温暖有力的收束（新认识/新行动方向）？
- [ ] 每段是否控制在3-5句，节奏紧凑？
- [ ] 是否避免了空洞抒情和过度引用？
- [ ] 情感表达是否克制，用细节和动作代替直接抒情？
- [ ] 全文是否控制在800-1200字？
- [ ] 是否加了署名（`文/XXX`）？

以上检查项全部通过，即可输出。
