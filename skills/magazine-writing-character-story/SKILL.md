## 能力

以"一个人物，一个品质，一段人生启示"为核心理念，选取一个真实人物作为故事主角，通过2-3个关键片段展现人物性格的某个侧面，在人物的高光与低谷之间勾勒出一条成长弧线。人物故事不同于叙事散文的"我"视角回忆——它要求作者站在观察者的位置，用第三人称讲述"他/她"的故事，让人物的行动和选择本身成为核心驱动力。人物故事也不同于情感观点文的"观点先行"——它不急于给出结论，而是通过人物经历的层层展开，让读者自己从故事中读出道理。全文围绕一个核心品质展开，不发议论，不贴标签，用画面和细节说话的叙事手段贯穿始终。

## 调用方式

```
/人物故事 <人物名/人物类型 + 核心品质或主题>
```

## 输入示例

```
/人物故事 窦骁 绅士的边界感
/人物故事 冯绍峰 从富二代到富一代的蜕变
/人物故事 傅莹 女外交家这样炼成
/人物故事 邱启明 我只是一介莽夫
/人物故事 大佬们的35岁 那些彷徨时刻
/人物故事 一位乡村教师 用一生守护一座学校
```

### 范文核心技法提取

**15762（窦骁）**：克制叙事的典范。全文没有一句"他很绅士"的评价，全篇靠动作和细节说话——"采访中女记者穿高跟鞋站久了，他不动声色地拉过一把椅子放在她身后""红毯上拧矿泉水瓶盖时，瓶盖朝向自己，水流自己喝完"。每一个细节都指向"绅士"这个品质，但从不直接说出这个词。读者自己从画面中得出结论，比作者告诉他要有力十倍。

**15768（冯绍峰）**：反差结构的教科书。开头先写"富二代"标签带来的先天质疑，这是人物的"负起点"；然后笔锋一转，用大量细节写他拍戏的拼命——寒冬下水、威亚吊到呕吐、连续工作36小时。前后反差的张力本身就构成了故事弧线。关键技法：不否定"富二代"这个标签，而是用行动重新定义它。

**15786（傅莹）**：以柔克刚的人物刻画。写女外交家最容易写成"女强人"脸谱——但范文用了一个极其细腻的手法：写傅莹在一场激烈谈判中，用给对方倒茶的动作化解了剑拔弩张的气氛。一个倒茶的动作，比一万字的"她很有智慧"更有说服力。人物故事的叙事魅力就在于此——高手用一个动作解决一切。

**15800（邱启明）**：用人物原话做叙事骨架。"我只是一介莽夫"这句话既是他对自己的自嘲，也是全文的叙事线索。每段故事都回到这句话的诠释上：在央视说真话被雪藏是"莽夫"，在直播中看不下去了是"莽夫"，最终用"莽夫"这个标签完成了人物形象的统一。人物原话不仅是素材，更是叙事结构。

**16333（大佬们的35岁也彷徨）**：群像叙事的要点在于"统一性"——每个大佬的故事虽然独立，但都指向"35岁困境"这个共同主题，时间线和逻辑线都清晰归位。技法是"先共性后个性"：先写35岁这个年龄段共有的焦虑（共鸣），再用每个大佬的个人经历展现不同的应对方式（差异化），最后合并为"低谷是必经之路"的统一结论。

## 结构模板

### 开头（150-250字）：高光画面或冲突瞬间抓住读者

**写法指导**：人物故事的开头必须是"让人想看下去"的——要么是一个特别有画面感的场景（让人想知道这是谁），要么是一个冲突或争议（让人想知道结果），要么是一个金句（让人想知道出处）。

```
可选开场方式：
- 高光画面式：在最精彩的瞬间定格，"红毯上，闪光灯亮成一片。她慢步走到发言台前……"
  （参考 15786 傅莹——从一场高难度国际谈判的紧张场景切入）
- 冲突争议式：从人物面临的最大争议写起，"有人说他只是一个靠家里的富二代……"
  （参考 15768 冯绍峰——先写质疑声，再写反转）
- 金句悬念式：以人物自己的话开头，制造悬念，"他说：'我只是一介莽夫。'"
  （参考 15800 邱启明——一句自嘲贯穿全文）
- 共情锚点式：用一个普遍困境切入，"35岁，你可能正处在焦虑中——那些今天的大佬，当年也一样。"
  （参考 16333 大佬们的35岁也彷徨——先用共情拉住读者）
```

示例开头句式（参考 15762）：
> "红毯上的窦骁，正弯腰拧一瓶矿泉水。周围的快门声此起彼伏，他没有抬头，拧开瓶盖后喝了一口。就是这样一个普普通通的动作——如果把镜头拉近，你会发现：瓶盖是朝向自己的。一个拧瓶盖的方向，暴露了一个人骨子里的教养。"

**关键**：开头必须让读者产生一个期待——"然后呢？""这个人是怎样的？"——这个期待会推动读者读完整个故事。

### 背景铺垫（80-120字）：2-3句交代人物背景

**写法指导**：背景铺垫不能写成简历。只挑核心的2-3个信息点，且必须与后文的人物成长有关。不会用到的信息不要写进来。

```
参考句式（参考 15786）：
"傅莹的第一份工作是翻译。不是外交科班出身，没有海外留学经历，她的起点在北京外国语学院的教室里。谁也没有想到，这个从内蒙古走出来的姑娘，有一天会成为中国外交场上的铁娘子。"
```

**三个原则**：
1. 背景的时间跨度控制在2-3句，不要超过一段
2. 背景信息只选"对人物性格有解释作用"的
3. 用背景制造反差——起点越低，后续的成长弧线越好看

### 核心故事（350-600字）：2-3个关键片段展现人物性格

**写法指导**：这是全文的主体。2-3个片段构成一个"证据链"，每个片段都指向同一个核心品质。片段之间应该有递进关系：第一个片段展示性格的一个侧面（往往是正面——人们看到的），第二个片段展示另一个侧面（往往是有争议的反面——人们忽视的），第三个片段（如有）展示人物在压力下的选择（最考验性格的时刻）。

**片段安排方式**：

| 顺序 | 功能 | 时长 | 参考范文 |
|---|---|---|---|
| 片段一（正面） | 展示人物最闪光的品质——让人"被圈粉" | 120-200字 | 15762窦骁帮女记者挪椅子 |
| 片段二（侧面/反面） | 展示人物的另一面——有争议、有弱点的真实 | 120-200字 | 15800邱启明的争议直播 |
| 片段三（选择/压力） | 在关键选择面前，人物做了什么——塑造完整形象 | 100-200字 | 15786傅莹谈判中的倒茶 |

**写片段的核心法**：每个片段就是一个"微型故事"。它有起承转合——有场景的开端、人物的动作、事态的发展、观众（或对手）的反应。每个片段独立来看都像一张"人物快照"，合在一起勾勒出一个完整的人。

示例片段（参考 15762）：
> "一次电影发布会上，记者提问环节出了个小插曲——前排一位女记者穿着高跟鞋站了太久，脚腕明显在发抖。窦骁注意到了。他没有直接说什么，而是趁着主持人切换话题的空挡，不动声色地从侧边拉了一把椅子，顺手推到她身边。动作很小，快得像没发生过。但那个女记者后来发了一条微博：'被一个人温柔地接住了。'"

### 转折（100-150字）：人物面临的困境或选择

**写法指导**：没有低谷就没有高光。转折是人物故事最重要的一段——它让人物从"偶像"变成"人"。转折可以是外部困境（职业瓶颈、舆论风波、健康危机），也可以是内心挣扎（自我怀疑、价值观冲突）。

转折部分必须回答一个问题：**"如果他/她真的那么好，为什么会遇到这种事？**

```
参考句式（参考 15768）：
"但好戏不是一开始就有人看的。冯绍峰演了几年的配角，拿到的角色台词不超过十句。有人当面说：'你不就是家里有钱吗？'这句话刺得他无话可说——他无法证明自己不是靠家里，因为起点确实比别人高。那几年他晚上睡不着，躺在出租屋里看着天花板想：如果离开'冯绍峰'这三个字，我还剩什么？"
```

**写好转折的三个要点**：
1. 转折必须在核心故事之后出现——先立人设，再推翻人设，才能重建
2. 转折要写人物的"痛感"——不是"遇到了困难"，而是"让他/她痛到整夜睡不着的事"
3. 转折不能靠作者说"他很痛苦"——需要用画面和动作表现痛苦（参考"冯绍峰躺在出租屋里看天花板"）

### 升华（80-120字）：这个人物带给我们的启示

**写法指导**：人物故事的升华必须走一条"暗线"——不能直接说"他告诉我们……"这种教学式结论。升华的方式是**让读者在人物的经历中看到自己**，或者**让读者产生"原来如此"的领悟感**。

```
良好示例（参考 15762 的升华逻辑）：
人物故事不必说出"绅士是后天习得的教养"——只需要让读者在看完窦骁为女记者挪椅子、为同伴解围、瓶盖朝向自己这些细节后，自己得出"原来真正的绅士是这样的"结论。升华藏在细节的累积中，不在最后一段。

可用句式：
- "有人问过他为什么这么做。他说：'没什么，就是习惯了。'"
   ——用人物自己的话收束，让读者自己品味
- "后来有人统计过，那一年有17位和他合作过的演员在采访中提到了他的'绅士'。数量本身并不重要，重要的是：17个人用了同一个词。"
   ——用数字和细节说话
```

**禁止使用的升华方式**：
- "他的故事告诉我们……"式的直接说教
- "这就是XX精神"式的标签式总结
- "我们要向他学习……"式的说教动员

## 技法要点

### 1. 用细节和画面代替形容词

人物故事最大的忌讳是"形容词堆叠"——写一个人"善良、勇敢、智慧"，不如写一个动作。

| 避免 | 推荐 |
|---|---|
| "他很有教养" | "瓶盖朝向自己，水流自己喝完" |
| "她非常机智" | "她把问题原封不动地还给了提问者" |
| "他很拼命" | "三天没合眼，助理递来的盒饭放在桌上，凉了也没打开" |
| "他很真诚" | "当着全组人的面，他说了那句所有人都知道但没人说的话" |

**核心原则**：写完之后逐句检查——如果一句话里出现了形容词（善良、勇敢、聪明、温柔、坚毅……），问自己：能不能用一个画面替代它？90%的情况下可以。

### 2. 一个核心品质贯穿全文

每个人物故事只讲**一个品质**。贪多嚼不烂。如果窦骁的故事写了他"绅士""努力""幽默"三个品质，读者一个也记不住。只写"绅士"这一个品质，读者会记住他。

**如何确定核心品质**：
- 读完所有素材后，问自己："这个人最打动我的一点是什么？"
- 选那"一点"作为全文的核心
- 不符合"这一点"的素材，再精彩也要删除
- 全文每一个片段都服务于"这一点"的证据链

**品质的选择原则**：品质本身越"反直觉"，故事越好看。
- "霸道总裁"太常见 → "克制的绅士"更有记忆点（窦骁）
- "女强人"太常见 → "柔韧的外交家"更有深度（傅莹）
- "富二代"太常见 → "从富二代到富一代的蜕变"更有叙事张力（冯绍峰）

### 3. 有低谷才有高光，人物必须有成长

人物故事不能写成"人物赞歌"——从头到尾都是优点的人不真实，也不动人。

**"双面刻画"原则**：
- 有正面就有侧面：写他待人温柔的同时，写他也有被"温柔"反噬的时刻
- 有高光就有低谷：写他成功之前，先写他失败的狼狈
- 有得就有失：写他得到某个机会，是因为放弃了另一个东西

**人物成长弧线的基本骨架**（参考 15768 冯绍峰）：
```
起点（被质疑） → 努力（拼命证明自己） → 低谷（瓶颈期） → 突破（作品说话） → 重构（重新定义"富二代"）
```

没有这个弧线，人物就没有厚度。

### 4. 引用人物原话增强真实感

人物的原话比作者的评价更有力量。引用人物原话的三种方式：

**A. 金句型**：一言以蔽之，成为全文的叙事线索
- "我只是一介莽夫。"（邱启明）——一句话定义了一个人

**B. 场景型**：在关键场景中引用人物说的具体的话
- "窦骁说：'绅士不是因为尊重别人，是因为尊重自己。'"

**C. 他人转述型**：引用他人对人物的评价，比作者评价更客观
- "合作过的导演说：'傅莹是我见过最会倾听的谈判者。'"

**注意**：引用不要超过全文的5%。人物的原话是"胡椒面"，撒一点点提鲜，撒多了就变成采访稿了。

### 5. 不发议论，让读者自己判断

这是人物故事区别于情感观点文和叙事散文的关键。人物故事的基本原则是：**作者隐身**。

- 不替读者总结"这个人物很好"
- 不替读者感叹"太感人了"
- 不替读者点评"他的做法是对的"

如果故事写到位了，读者自然会得出这些结论。如果你忍不住想写一句"他真的很了不起"，写完之后删掉它。看看没有这句议论，故事的力量是不是反而更强。

**替换方案**：
| 想写的议论 | 替换方案 |
|---|---|
| "他真的很伟大" | 写他做的事，不写对他评价 |
| "这种精神让人感动" | 写一个让人眼眶发酸的动作细节 |
| "这个选择是对的" | 写这个选择带来的结果 |
| "所有人都会敬佩他" | 写旁观者的反应（同事、合作方说了什么） |

## 人物故事与其他 skill 的区别

本 skill（人物故事）与 `skill-narrative-prose.md`（叙事散文）和 `skill-emotional-opinion.md`（情感观点文）互补但不重叠：

| 维度 | 人物故事 | 叙事散文 | 情感观点文 |
|---|---|---|---|
| 叙事视角 | 第三人称观察者——"他/她" | 第一人称回忆——"我" | 第一人称或全能视角 |
| 核心驱动力 | 人物品质——"他是什么样的人" | 叙事线索——"发生了什么" | 观点论证——"我认为什么是对的" |
| 人物作用 | 人物是全文的唯一主角 | 人物是叙事的一部分 | 人物是观点的例证 |
| 议论方式 | 不发议论，让读者自己判断 | 夹叙夹议，从叙事自然生长 | 议论先行，故事支撑观点 |
| 结尾 | 余韵留白，不总结不升华 | 回到当下或留白沉思 | 观点收束，给出新视角 |
| 字数范围 | 1000-1500字 | 800-1200字 | 1000-1500字 |

**选择原则**：如果要写的就是"这个人"——用他/她的经历展示一个品质，选人物故事。如果讲的是"我的经历"，选叙事散文。如果要论证"什么道理是对的"，选情感观点文。

---

## 输出约束

- **字数**：1000-1500 字（中文）
- **署名格式**：文末空一行，右对齐署名，格式为 `文/XXX`（使用调用时指定的虚构作者名；如未指定，使用默认作者名"佚名"）
- **不允许**：形容词堆叠、直接说教评价、多品质杂乱无重点、没有低谷只有高光的"造神式"写作、第一人称叙事（必须是第三人称）、政治敏感内容
- **必须**：有一个贯穿全文的核心品质、至少2个关键片段（正面+侧面或正面+低谷）、至少3个具象的动作/细节画面、引用至少1处人物原话或他人转述、开头有画面感或冲突感吸引读者、结尾有余韵不落说教
- **人物关系**：涉及真实人物时，需基于公开可信素材；涉及虚构人物时，标注"本故事根据真实经历改编"

## 示例

### 示例 1

**用户输入**：
```
/人物故事 窦骁 绅士的边界感
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://<your-magazine-api>.workers.dev/search?q=窦骁+绅士+教养+细节&top_k=3"` 和 `curl "https://<your-magazine-api>.workers.dev/search?q=演员+修养+低调&top_k=3"`。读取 ID 15762 学习人物故事的开场方式和片段组织手法。

2. **确定核心品质**：
   - 核心品质：**有边界感的绅士**
   - 为什么选这个：窦骁的"绅士"不是泛泛的"对女生好"，而是体现在"瓶盖朝向自己"、"给同伴留台阶"这类有边界的细节上——他的绅士感里带着聪明和克制

3. **确定结构**：
   - **开头（高光画面式）**：红毯上，闪光灯成片，窦骁弯腰拧一瓶水。他喝了一口，瓶盖拧回去的时候，瓶口朝外，标签朝里——只有自己看得见瓶盖上的商标。一个细节，定调。
   - **背景铺垫**：加拿大长大，不是科班，从配角做起，模特转行演员。他的"绅士"不是天生的——是经历了很多"被忽视"之后，有意识的选择。
   - **片段一（正面——绅士的细节）**：发布会后，女记者穿高跟鞋站太久。窦骁没说话，中途借着上台的动作，顺手把旁边一把椅子挪到记者身后。动作轻到无人察觉——但记者后来发了微博，说"被温柔接住"。
   - **片段二（侧面——绅士的聪明）**：有媒体采访，话题引到女搭档的敏感八卦。窦骁没有直接打断，而是拿起水杯说"我渴了，你渴吗"——把话题引开。他保护的不仅是女搭档，更是所有人的体面。
   - **片段三（低谷——绅士的反面）**：他也会因为"太绅士"被误解。有人觉得他刻意，觉得假。他回应："我不是对所有人都好。我只是不想让任何人在我面前难堪。"——这句话点题，解释了"什么是真正的好"。
   - **结尾（余韵）**：有人问他为什么要做这些事。他说："不是什么大事。就是习惯了。"不需要总结，不需要升华。一个"习惯了"，说明了一切。
   - **时间线**：按场景切换，不依赖时间顺序，而是品质的不同切面

4. **输出**：一篇1000-1200字的人物故事，署名 `文/XXX`，以"有边界感的绅士"为核心品质贯穿全文，至少3个细节画面替代形容词，至少1处人物原话引用，不发议论，让读者从片段中自己拼出人物形象。

### 示例 2

**用户输入**：
```
/人物故事 一位乡村教师 用一生守护一座学校
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://<your-magazine-api>.workers.dev/search?q=乡村教师+守护+奉献+真实人物&top_k=3"` 和 `curl "https://<your-magazine-api>.workers.dev/search?q=大山+教育+坚持+困顿&top_k=3"`。读取 ID 16333 学习群像叙事中的低谷刻画方法。读取 ID 15768 学习"从困境到坚守"的成长弧线写法。

2. **确定核心品质**：
   - 核心品质：**执着的守护**
   - 为什么选这个：乡村教师的动人之处不在于"教书"这个动作，而在于"明知条件艰苦、前途渺茫还是不走"的固执。核心是"守护"——守护学校、守护孩子、守护一个看起来没什么希望的承诺。

3. **确定结构**：
   - **开头（冲突争议式）**：学校快被撤了，整个镇只剩7个学生。教育局的人来了三趟，每次都说"合并吧"。教师张老师站在校门口，什么都没说。他不走的原因，要从二十年前说起。
   - **背景铺垫**：张老师是本地人，高中毕业那年，镇上的老校长找到他，说学校缺老师，你能不能来。"干一年"变成了一干二十年。他不是没有机会走——县城学校开过更高的工资。
   - **片段一（正面——为什么留下）**：第一年冬天，教室的煤炉坏了，孩子们冻得跺脚。他把自己的棉袄脱下来裹在最小的孩子身上，自己穿着单衣讲了一上午的课。不是没有棉衣——下一件要等到下个月发工资。这件事他从来没跟任何人提过。是当年的学生后来回来看他时，才说出来的。
   - **片段二（低谷——动摇的时刻）**：最困难的那年，学校只剩三个年级，来应聘的老师来了又走，最长的待了两个月。妻子也劝他：你图什么？那天下雨，屋顶在漏水，他用盆接着。雨水滴答滴答打在盆里，他坐在教室后面想了很久。第二天，他站在校长室门口，说：我再去镇上走一趟。
   - **片段三（选择/坚持）**：他走了几十里山路，一家一家地敲门。有些家长已经把孩子送去县城了，他还是去了。不为别的——"跟家长说一声'学校还在'。"这个"还在"，他守到了现在。
   - **结尾（余韵）**：有人问他，如果有一天学校真的被撤了呢？他说："那至少这些孩子知道有人来过他们家，告诉过他们'学校还在'。"他没有说是为了孩子的前途、为了乡村的未来——他只是说了一句"学校还在"。
   - **时间线**：二十年前（开始）→ 第一年冬天（坚守的起点）→ 最困难那年（动摇的时刻）→ 现在（小高潮，上门家访）→ 结尾（未来——一句回答收束）

4. **输出**：一篇1200-1500字的人物故事，署名 `文/XXX`，核心品质"执着的守护"贯穿全文，用三个关键片段（棉袄→漏水屋顶→上山家访）展现人物弧线，至少2处人物原话引用（"学校还在"重复出现作为叙事线索——但只在三次关键位置出现），不发一句议论，让读者从"他什么都没说但什么都没说"的画面中自己感受到力量。

## 写作检查清单

写作完成后逐项自查：

- [ ] 是否只有一个贯穿全文的核心品质？（贪多是大忌）
- [ ] 开头是否有画面感或冲突感，让读者想继续看下去？
- [ ] 是否有至少2个关键片段（分布方式应为"正面+侧面"或"正面+低谷"）？
- [ ] 是否每个片段都是"微型故事"——有场景、有动作、有结果？
- [ ] 是否有人物的低谷或困境？（不能只有高光）
- [ ] 是否用动作/细节替代了形容词？（逐句检查，避免"他很善良/勇敢/聪明"）
- [ ] 是否引用了至少1处人物原话或他人转述？
- [ ] 是否保持了第三人称叙事，没有使用"我"？
- [ ] 是否避免了直接说教和议论？（"让我们看到……""他告诉我们……"等句式要删除）
- [ ] 结尾是否留有余韵，没有做"总结式升华"？
- [ ] 全文是否控制在1000-1500字？
- [ ] 是否加了署名（`文/XXX`）？
- [ ] 每个片段是否都服务于核心品质这条主线？（不相关的素材是否已删除）
- [ ] 人物是否有"成长"——从起点到终点的变化是否可见？

以上检查项全部通过，即可输出。
