## 能力

以"以小见大"为核心理念，从一个具体物件、一个日常场景、一段微小经历切入，用克制而细腻的笔触层层展开，最终抵达普遍的情感或人生感悟。不空发议论，不直抒胸臆，让细节本身说话。

## 调用方式

```
/抒情散文 <主题或素材>
```

## 输入示例

```
/抒情散文 母亲的一把旧伞
/抒情散文 深夜的火车站
/抒情散文 一个打碎的茶杯
```

## 结构模板

### 开头（150-200字）：从一个具体物件/场景切入

**写法指导**：不要用"母爱是伟大的"这类抽象开头。直接写一个具体的物件、场景或瞬间。用白描手法，不加修饰语，让读者"看见"画面。

```
可选开场方式：
- 物件式：从一件物品写起（一把伞、一封信、一个旧茶杯）
- 场景式：从一个画面写起（雨夜、车站、厨房的灯光）
- 细节式：从一个微小动作写起（母亲的手势、父亲的背影、陌生人的一个眼神）
```

示例开头句式（参考 19728）：
> "我到现在还记得那把伞。深蓝色的，边缘磨出了白线，伞骨断过一根，用胶布缠着。"

### 展开（300-500字）：细节堆叠，层层推进

**写法指导**：这是文章的主体。核心原则是"用场景代替评价，用细节代替抒情"。

- **第一层**：围绕开头的物件/场景，展开第一个具体记忆片段。写"发生了什么"，不写"我有什么感受"。
- **第二层**：第二个记忆或细节，与前文形成递进或对比。可以拉长时间跨度（小时候 → 长大后），也可以转换视角（当时觉得 → 现在回想）。
- **第三层**（可选）：引入一个看似无关的细节或对照，拓宽文章的层次（参考 19728 从母爱自然过渡到师恩的方法）。

**关键**：每个段落都要有一个"画面锚点"——一个让读者能"看见"的具体细节。没有画面锚点的段落就是空发议论，必须删掉。

### 结尾（100-200字）：留白或点到即止

**写法指导**：抒情散文最忌在结尾说尽。好的结尾应该：

- **留白式**：回到开头的物件/场景，但多了一层意味。不说"我明白了母爱"，而是写"那把伞还在老地方，只是颜色又淡了些"。
- **意蕴式**：一个与开头呼应的画面或动作，让情感像涟漪一样扩散开去。
- **克制式**：用一个短句收束，让读者自己去填补余下的情感空间。

禁止使用的结尾方式：
- 写一段"通过这件事我明白了……"式说教总结
- 喊口号（"母爱真伟大""珍惜身边的人吧"）
- 强行升华到与全文无关的大道理

## 技法要点

### 1. 克制叙述

抒情散文的力量不在于"说了多少"，而在于"留了多少"。

| 避免 | 推荐 |
|---|---|
| "那一刻我感动得热泪盈眶" | "我把头扭向窗外，没有说话" |
| "母亲多么辛苦啊" | "她的手指上缠着胶布，洗菜的时候沾了水，又松开了" |
| "我深深感受到了父爱的伟大" | "饭桌上他什么也没说，只是把那只鸡腿夹到了我碗里" |

**规则**：永远不要让文中人物替读者说出情感。让场景和细节本身去"说"。

### 2. 以小见大

选择一个足够小的切入点——小到让读者觉得"这也能写一篇文章"。然后从这个点自然地延伸出去。

- 好的切入点：一把缺了齿的木梳、父亲修了又修的旧手表、车站便利店的热饮机
- 不好的切入点："论母爱""谈人生""说友谊"

切入点和主题的关系：切入点越小，文章越有张力。从一张旧车票写到聚散离合，比直接写"离别"高明得多。

### 3. 比喻运用

比喻是抒情散文的魂，但要"藏"着用。

- **用物象作比**：选择生活中常见的物象，不要用"像大海一样""像阳光一样"这类陈词滥调
- **比喻要服务于情感**：每个比喻都应该让读者对情感的理解更深一层，而不是炫技
- **少而精**：一篇 800 字的文章，2-3 个精妙的比喻远胜于 8-10 个平庸的比喻

好的例子（参考 24725）：
> "母亲的关心像一件织得太紧的毛衣，穿上暖和，却也勒得喘不过气。"

### 4. 情感控制

抒情散文的情感应该是"含着的"，不是"泼出去的"。

- **延迟表达**：写到具体事件时先不写感受，让读者先经历事件本身
- **用行动代替抒情**：用"她去厨房热了杯牛奶"代替"她很关心我"
- **控制情感峰值**：一篇文章只能有一个情感最高点，其他部分要为这个高点做铺垫

## 风格特征总结

| 特征 | 说明 |
|---|---|
| 切入点 | 一件小事、一个物件、一个瞬间，越小越好 |
| 细节处理 | 堆叠具象细节，不空发议论，让细节自己说话 |
| 情感表达 | 克制、含蓄，"含"着写而不是"泼"着写 |
| 结尾处理 | 留白、点到即止，回到起点但多了层意味 |
| 整体结构 | 由实到虚：物/事 → 记忆/场景 → 感悟/韵味 |
| 语言风格 | 平实、细腻、白描为主，适当使用比喻和通感 |

## 输出约束

- **字数**：600-1000 字（中文）
- **署名格式**：文末空一行，右对齐署名，格式为 `文/XXX`（使用调用时指定的虚构作者名；如未指定，使用默认作者名"佚名"）
- **不允许**：空发议论、直接抒情、说教总结、政治议论、引用官方宣传口径
- **必须**：有一个具体的切入物件或场景、至少两个细节画面、结尾留白

## 检索策略

写作前需参考类似主题的范文，通过以下 API 检索：

```bash
# 1. 按关键词搜索相关范文（推荐先使用语义搜索）
curl "https://<your-magazine-api>.workers.dev/search?q=母爱+细节+龙眼&top_k=5"

# 2. 已知 ID 直接读取全文
curl "https://<your-magazine-api>.workers.dev/article/19728"
curl "https://<your-magazine-api>.workers.dev/article/24725"
curl "https://<your-magazine-api>.workers.dev/article/24924"
curl "https://<your-magazine-api>.workers.dev/article/22027"

# 3. 按主题搜索（替换关键词即可）
# 亲情类: curl "https://<your-magazine-api>.workers.dev/search?q=父亲+沉默+背影&top_k=5"
# 怀旧类: curl "https://<your-magazine-api>.workers.dev/search?q=童年+老家+物件&top_k=5"
# 感悟类: curl "https://<your-magazine-api>.workers.dev/search?q=陌生人+温暖+小事&top_k=5"

# 4. 获取暗渡陈仓风格以外的所有范文（抒情散文通常不在暗渡列表中）
# 可先获取所有暗渡 ID 做排除，再搜索
```

**搜索关键词建议**：
- 与主题直接相关的关键词（如主题是"母爱"，搜"母爱+伞""母爱+背影""母亲+细节"）
- 与切入物件相关的关键词（如从"旧伞"切入，搜"伞+回忆"）
- 与情感基调相关的关键词（如"温暖+细节""怀旧+物件"）
- 可参考"参考范文"ID 对应的标签信息（见 `docs/specs/tag-system.md`），按"主题标签=亲情"+"开头方式=故事式"等组合筛选

**注意**：抒情散文的风格学习重点不在于搜同一主题，而在于学同一"技法"。搜到任意一篇情感克制、细节堆叠的优秀范文都比搜到同主题但写法粗糙的文章更有价值。

## 示例

### 示例 1

**用户输入**：
```
/抒情散文 母亲缝补过的一件旧校服
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://<your-magazine-api>.workers.dev/search?q=母亲+针线+旧衣服&top_k=3"`，阅读返回的范文，学习它们如何用缝补衣物写母爱。同时读取 ID 19728 和 24725 学习细节控制和情感递进。

2. **确定结构**：
   - 开头：从衣柜深处翻出旧校服，描写上面的针脚
   - 展开：回忆母亲在灯下缝补的场景（第一个画面）→ 对比"我"当时嫌弃校服破旧的态度（第二个画面，转折点）→ 延伸到母亲其实一直在用这种方式"缝补"生活中各种破洞（递进）
   - 结尾：回到当下的旧校服，发现针脚已经泛黄，但依然整齐

3. **输出**：一篇 700-900 字的抒情散文，署名 `文/XXX`，情感克制，不出现"母爱伟大"类表述。

### 示例 2

**用户输入**：
```
/抒情散文 深夜便利店的热饮柜
```

**AI 处理方式**：

1. **检索参考范文**：执行 `curl "https://<your-magazine-api>.workers.dev/search?q=深夜+陌生人+温暖&top_k=3"` 和 `curl "https://<your-magazine-api>.workers.dev/search?q=城市+孤独+细节&top_k=3"`。阅读范文学习如何在城市题材中控制情感。读取 ID 22027 学习从生活场景折射普遍感受的技巧。

2. **确定结构**：
   - 开头：深夜加班后走进便利店，热饮柜暖黄色的灯光
   - 展开：描写便利店里的其他人——夜班司机、刚下晚自习的学生、带孩子的年轻妈妈（并列式群像，参考 22027 的写法）→ 每个人都从热饮柜取走一杯热饮，各自消失在夜色里→ 想起自己在这个城市辗转的几个住址，每一次都是便利店最先记住你的脸
   - 结尾：拿起一杯热饮，感受穿透纸杯的温度——和家乡冬天母亲塞过来的热水袋，是同一个温度

3. **输出**：一篇 600-900 字的抒情散文，署名 `文/XXX`，通过便利店这一现代都市符号，写出"过客之间的短暂共鸣"。

## 写作检查清单

写作完成后逐项自查：

- [ ] 开头是否从一个具体物件/场景切入，而非抽象说理？
- [ ] 每个段落是否至少有一个"画面锚点"（让读者能"看见"的细节）？
- [ ] 是否避免直接说出情感（"我很感动""他真辛苦"等）？
- [ ] 比喻是否不超过 3 个？是否都来自日常物象？
- [ ] 结尾是否留白，没有总结说教？
- [ ] 全文是否控制在 600-1000 字？
- [ ] 是否加了署名（`文/XXX`）？
- [ ] 是否有至少两个不同的记忆/场景细节？

以上检查项全部通过，即可输出。
